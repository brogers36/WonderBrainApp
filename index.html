On Android

Open WonderBrain in Chrome. Tap the browser’s ⋮ menu and choose Install app. It may appear under Add to Home screen or Install and create shortcut. Choose Install when offered.

On iPhone or iPad

In Safari, tap Share → Add to Home Screen. Turn on Open as Web App if shown, then tap Add.

Already have the old shortcut? After the new app appears, remove the old shortcut with the Chrome badge. If installation is not offered, keep this page open for a moment, explore a discovery, and check the browser menu again. Installation and icon appearance depend on your browser and device.
